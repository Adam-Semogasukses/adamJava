Kalkulator penghitung luas bangun ruang dan bangun datar.
Menerapkan prinsip oop (class, method).

versi pertama: basic
  Hanya bisa menghitung luas bangun ruang (bola, kubus, balok)

versi kedua: tanpa switchcase
  menggunakan percabangan
  bisa menghitung luas dan keliling hingga volume

dibuat dengan java menggunakan cli apache netbeans
